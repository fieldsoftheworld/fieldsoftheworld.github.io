Mapping the world's agricultural fields at scale

Fields of The World (FTW) is an open ecosystem for agricultural field boundary detection — combining a global benchmark dataset, baseline ML models, inference tools, and web applications for geospatial workflows in the cloud.

Most countries lack comprehensive maps of their agricultural fields. FTW leverages open Sentinel-2 satellite imagery and machine learning to detect field boundaries at scale, enabling land use monitoring, food security assessments, and agricultural intelligence worldwide.

Benchmark Dataset

Baseline Models & Tools

Pretrained segmentation models and a CLI for downloading data, running inference, and producing fiboa-compliant vector output.

Web Application & API

Browser-based inference over any area of the world — no code required. Powered by an open API deployed on AWS.
